2.  **Understand Tensor Parallelism:**
   - Tensor parallelism (TP) is a model parallelism technique where individual tensors (weights/activations) within a layer are partitioned across multiple GPUs.
   - Common in LLMs for large linear/attention layers.
   - How it reduces per-GPU memory:
     - Weights are split: Each GPU stores only a shard
