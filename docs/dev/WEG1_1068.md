## 1. The design in one paragraph

Both phase host pools are built from ONE absolute upstream knob,
`--hicache-size` (GB), the TP pin ROW-coupled to the PP pool
(`phase_flip_boot.py`, `#1068 TP PIN ROW MISMATCH` raises on divergence);
the mamba anchor pools of both phases from `--hicache-mamba-host-mib` (MiB
per rank, MIN-synced across the group, `synced_from_local=` on the
provenance line). The prefetch budget is the upstream property
`prefetch_capacity_limit = int(fraction x mem_pool_host.size)` read live
(no stored copy, no floor, no symmetrisation); the rate verdict is the
upstream counter form in both roles (`prefetch_tokens_occupied`). A
`rate_limited` verdict is never a decline: the request is marked deferred,
retried every pass in `kv_arrival_seq` order, held from prefill by PP0 only,
and every mark has exactly one named exit (`LANDED`, `DEFER EXPIRED`,
`DEFER RELEASED`, `DEFER DROPPED`, `DEFER CLEARED AT CUTOVER`). At the
cutover the WHOLE run-willing population (retracted residents AND queue
occupants) is re-issued through the one upstream intake site
(`_add_request_to_queue -> _prefetch_kvcache`) under the incoming binding
generation, in arrival order, occupants not stamped as retracts. Every
exit behind the #915 gate has a term and one line. The per-request seam
copy (A) and its restore path are deleted; the HiCache store is the single
carrier. The verdict stays PP0 (#968).

## 2. Bounded loss (the commit sentence of section 4.5, verbatim)

Deleting the per-request seam copy loses at most chunked_prefill_size
(4096, log 175) tokens of recompute per resident and cutover, and only for
residents whose prompt fits ONE chunk and that are re-allocated in the

structurally (schedule_batch.py:3278-3279 PREFILL INCOMPLETE, 7 refusals x

153597-153743, 154534-154536, 191117-191133, 191593-191609, 191645-191658),

4688/4690/4735, 191591/191602/191607); the measured restore on that boot
was exactly one request (7fb95686, 67 rows, log 151763-151764/151812-151813/
151861-151862). The store path carries a superset of the copy (all 16
layers vs the rank-local stage slice, #706) plus the GDN leaf anchor at

copy extent 14922, log 154287 vs 191645) and is the single carrier after
this commit, conformant with the one-chunk law (#939).

## 5a. Named deviations from the spec (slice 5 and its fix)

1. Host floor 16 GiB, not the spec's "16 GB" (section 5): unit slip,
   operator decision 1; the gate `host_ledger_preflight.sh` applies GiB.
   Consequence on the Boot-2 box: S = 5 instead of 6.
2. The provenance line of section 4.6 ("requested/ledger/EFFECTIVE") is
   spelled `demand=/ledger= -> EFFECTIVE=` for S and
   `formula=/knob= -> EFFECTIVE=` for M: "requested" does not say WHO
   requested; the demand (S) and the knob (M) do.
3. `cell_pp0` is the MAX over the previous log's `cell_pp=` fields, not
   "the last HOST-LEDGER line" (section 5): pool_host/base.py:140-147 sizes
   each rank as int(S*1e9 // cell_r) and the MIN sync makes the rank with
   the largest cell binding; the literal last line is PP2's 8192 and would
   size PP0 short. The knob `WEG1_CELL_PP0_BYTES` takes precedence over the
   log.
4. A4 "K == input_len-1 (never 366211)" is not checkable from the
   `#1028B FETCH CAP` line alone (input_len is not on it); built as
   `kv != pool_rows` and `lost <= chunk`.
5. A9: `defer_refused` is read and printed, never a FAIL term. The
   `[#915 prefetch-gate]` counters are boot-cumulative over both phases
   (single emitter unified_radix_cache.py:1873, nothing clears
   PREFETCH_GATE_COUNTS), so a spec-conformant boot with TP-phase
   symmetric-vote declines would otherwise fail; the FAIL terms are the
   declines into recompute (undeferrable, defer_expired, defer_dropped).
6. A11.5 is existential over the big PP0 cutovers (at least one fully
   materialised), with the universal per-rid form living in A5; the
   selftest pins both (gap in one cutover: A5 FAIL + A11.5 PASS naming the
   gap cutover; gap in all: both FAIL).
7. The "ratio zombie" claim, measured: launcher 0 hits for `HICACHE_RATIO`,
   `_HR_FALLBACK`, `--hicache-ratio`, `devtools/weg1_host_sizing`;
   python/ 0 hits for `HICACHE_RATIO` and `_HR_FALLBACK`. The token
