# #421 unwired-feature detectors

The four detectors behind `docs/dev/AUDIT_421_UNWIRED.md`. They exist in the
repo rather than in a scratch directory so the audit can be re-run against a
later tip — a finding table without a reproducible detector ages into folklore.

All of them are pure `ast` analysis over a source tree. No imports of sglang,
no torch, no CUDA, no GPU.

## Detector A — flag / env consumer classification

Which fork-added CLI flags and `SGLANG_*` env vars have production consumers.

```
cd <scratch dir holding the name lists>
AUDIT421_ROOT=/path/to/worktree python3 detA_flags_envs.py fields delta_fields.txt
AUDIT421_ROOT=/path/to/worktree python3 detA_flags_envs.py envs   delta_envs.txt
```

Build the name lists as a set difference against upstream — the CLI surface
must come from the `ServerArgs` dataclass, **not** from `add_argument` (only 27
of the fork's flags are declared that way; the rest are generated by
`arg_groups.arg_utils.add_cli_args_from_dataclass`).

Finds absent wiring. Cannot see partial wiring, computed attribute names
(`getattr(sa, prefix + name)`), or env bridges — see §1.2 of the audit.

## Detector B — always-default parameter

A feature parameter every production call site omits or passes `None` to.

```
python3 detB.py <tree_root> [--paths a,b,c] [--all] [--json out.json]
python3 detB2.py <tree_root> [--paths a,b,c]      # degenerate derivation
```

Two details are load-bearing and were only found by calibrating:

- **B propagates forwarding taint.** A site passing `foo=foo` proves nothing
  when `foo` is the enclosing function's own always-default parameter. Without
  the fixed point over that relation, B classifies the #394 case WIRED.
- **B2 strips docstrings before matching.** Against raw source a function
  scores `has-measured-source` because its *prose* says "measured" while every
  actual source is a nameplate query.

## Detector C — asymmetric gate

An escape hatch with real consumers that a structurally parallel sibling path
ignores. This is the only detector that can see the #197 shape; a consumer
count never will.

```
python3 detC.py <tree_root> --env SGLANG_GGUF_DENSE_VOCAB
```

Entities come from the gate's own docstring, so C cannot fire on an
undocumented gate. Trust the STRONG tier (100 % precision on the one case with
known ground truth); the weak tier ran at 10 %.

## Detector D — module reachability

Ranks fork-only modules by the fraction of their public API that nothing in
production references.

```
AUDIT421_ROOT=/path/to/worktree python3 detD_module_reachability.py
```

Reads `forkonly_srt.txt` (fork-only production modules, one relative path per
line) from the working directory. Aggregate per module — the raw name-level
output is dominated by Triton kernels, `_ref` test oracles and re-exports.
When checking a *package*, exclude its own `__init__.py`: a package that
re-exports its submodules is part of the feature, not a consumer of it.
