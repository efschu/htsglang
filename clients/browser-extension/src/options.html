Video-Enhance on the fly

This extension is one client of the server's public GET /v1/video/enhance endpoint. Anything that opens an HTTP URL — VLC, mpv, ffmpeg, curl — is an equally valid client of the same endpoint; the extension only saves you from copying the URL by hand.

The host permission for this origin is requested on save, not held permanently.
Ignored by presets that keep the source size.
0.5 is the 4K headroom arm; 1.0 is full quality.
Empty means to the end of the source.
